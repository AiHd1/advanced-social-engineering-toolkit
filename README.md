# Advanced Social Engineering Toolkit (ASET)

ASET is a comprehensive toolkit designed for educational purposes to simulate and study advanced social engineering attacks in a controlled environment. This toolkit includes various modules for phishing, pretexting, and other social engineering techniques.

## Features
- **Phishing Module**: Simulate phishing attacks using custom templates.
- **Pretexting Module**: Create and send customized pretexting messages.
- **Error Handling**: Robust error handling to ensure smooth operation.
- **Logging**: Detailed logging for all actions performed by the toolkit.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/advanced-social-engineering-toolkit.git
   cd advanced-social-engineering-toolkit
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
### Phishing Module
To use the phishing module, run:
```bash
python main.py phishing --template example.html --target example@example.com
```

### Pretexting Module
To use the pretexting module, run:
```bash
python main.py pretext --message "This is a pretext message" --target example@example.com
```
